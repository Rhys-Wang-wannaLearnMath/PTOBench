# 旧路径清理与软件验收 Implementation Plan

**目标：** 删除旧身份映射、旧 Agent runner、旧 Session 执行兼容与导出 Workspace 路径；保留 `evaluator/agent_dispatch.py` 作为唯一 Agent 启动入口，移除 PTOBench 根目录 `ops/`，并在不占用 NPU 的情况下完成软件回归。

**架构：** Plan 01–03 的专用用户、真实 Workspace 和 Pi 沙箱已通过后，按全仓调用关系移除旧实现。最终只保留专用 Agent 用户 + Bubblewrap + POSIX DAC 一条 Agent 路径；不留旧配置解析、迁移适配、兼容分支或自动回退。固定 dispatcher 位于既有 `evaluator/` 内。保持 CLI、Broker、Snapshot、Finalize、Profile 和非 Workspace 归档合同。

**依赖：** Plan 01–03 全部通过。

**Tech Stack：** Python、pytest、Linux 只读文件视图检查与 Git。

**Spec：** [`00-overview.md`](00-overview.md)，尤其是唯一运行路径、历史 Session 处理与最终验收条件。

## 全局约束

- 只删除 PTOBench 自有的旧身份/导出路径；保留 Candidate Worker、Snapshot、Action freeze、Session integrity 与非 Workspace 归档机制。特别保留或按新目录调整 `evaluator/sandbox_supervisor.py::copy_tree` 对 `agent/native`、CANNBot session/dispatch/tool 记录的活动归档调用；它与旧 `Broker.export/sync_source/feedback` 不是同一路径。删除旧调用前用 `rg` 确认其调用者并更新对应归档测试。
- 不改 Case、Fixture、Seed、Reference、Baseline、CV、`case_selection/` 或用户历史数据。
- `lightweight_e2e` 不得成为正式源码、测试、启动、打包或部署依赖。

## Review Focus

- 旧 Session 在任何完整性自动修复前拒绝，拒绝前后整棵 Session 树 hash 相同。
- 搜索结果必须区分 PTOBench 自有旧代码、负向测试、历史文档与 vendor 内容，避免误删。
- 清理后不存在旧 runner、配置解析或运行时回退入口；新路径仍通过完整软件回归。
- 核查已退役的 `state_residency_inventory_20261028.csv` 与读取它的 allowlist/策略逻辑。当前计划基线中没有该 CSV；只有找到实际残留读取器时才删除相应逻辑和专属测试。不要把仍被 `workflow.py`、`candidate_execution.py` 与 baseline/certification 比较使用的 `evaluator/timing_policy.py` 当成该旧清单：它记录测量窗口与编译 Tensor ABI，不做 Case allowlist；本轮保留该执行合同，避免改动 Ref/Baseline/CV。
