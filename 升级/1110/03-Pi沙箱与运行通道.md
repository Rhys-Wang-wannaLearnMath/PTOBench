# Pi 沙箱与运行通道 Implementation Plan

**目标：** 让 Basic/CANNBot Pi 以专用 Agent 用户运行，同时只看到当前 Session 的真实 Workspace，并保持 Pi 私有文件、Socket、Gateway、CLI 和网络边界。

**架构：** 复用 `isolation.agent_command` 与 `View.argv`，外层只挂载当前 Session 的 `workspaces/` 一个 RW bind。共享组给 Agent 读写 Candidate、只读 Context/Outputs、连接必要 Socket 的能力；Bubblewrap 控制可见路径。Broker、Gateway、Candidate Worker 和 NPU/HCCL 不切换账号。

**唯一运行路径：** 所有 Pi Agent 启动均须经专用 Agent 用户和 Bubblewrap。关闭沙箱、非 Pi backend 或不完整配置必须报错退出；不得调用 `run_legacy`、以 Broker 身份启动 Agent 或切换到旧导出 Workspace。

**依赖：** Plan 01、02 完成；临时 Workspace DAC 已通过。

- Modify `evaluator/network_proxy.py::serve_api`、`bridge`；`modes/cannbot/tools.py::ToolServer.__init__`：Socket 组和 mode。

- Create `evaluator/tests/test_sandbox_supervisor.py`：覆盖 `run` 的唯一路由和 fail-closed 分支。
- Modify `evaluator/tests/test_isolation.py`、`test_mode_provider.py`、`test_cannbot.py`。

## 步骤

- [ ] 先添加 mount manifest 测试：Agent 只存在一个当前 Session `workspaces/` 的 RW mount；不存在 Candidate 池、public Workspace 副本或 Workspace 链接 mount。每个新 Worker 由同一挂载立即可见。
- [ ] 更新 `agent_command` 与 Pi Shell 子 Sandbox：Candidate 独立 mount 删除；子 Sandbox 继承外层的 Workspace 权限或仅对同一个 Workspace 根重新 bind 一次。两层都能写 Candidate，不能改 Context/Outputs、Worker 根或 Workspace 根。增加路由测试，证明关闭沙箱或不支持的 backend/config 直接失败且不调用旧 runner。
- [ ] 在 Broker 主机文件系统中通过 ACL 给共享组最小化的父目录遍历权和运行时读取权。当前 HOME 是 `0700`，只为实际需要的 PyPTO Python 环境、Pi/Node 二进制及其依赖、PTOBench 客户端和 Bubblewrap 源路径设置 ACL；不给 Agent 列举整个 HOME 的权限，不开放 Evaluator/Launcher/Broker/mode 源码。`getfacl` 验证 ACL mask 生效。
- [ ] Socket 使用 Broker owner、共享组、`0660`；Socket 父目录给共享组可遍历但不可列目录。验证 CLI RPC、Model Gateway 与 CANNBot Socket 可连接；其他用户不能连接或枚举。不要将 API Key 放进 Agent 环境或 request 文件；仅 Gateway 有上游 Key。
- [ ] 将 `agent/pi` 设置/会话目录按所需读写权限交给 Agent 与 Broker 共享。Pi shell 子 Sandbox 继续遮蔽该目录和 Agent session 路径。Pi File Guard 和 shell wrapper 必须保持 Broker 可管理、Agent 不可替换；如同一可写父目录使 Agent 可换掉 guard 文件，改为只读独立 mount/不可写入口并添加原生工具及 Shell/Python 越界测试。
- [ ] 真实 Pi 工具测试：Native `read/write/edit/grep/find/ls` 对 Pi 私有设置和 Session 文件被 File Guard 拒绝；Shell、Python、路径遍历、符号链接、硬链接别名和 `/proc` 不能越界。Pi 自身仍能加载配置、写会话和锁文件，Broker 退出后能归档。
- [ ] 验证 Agent 只能看到当前 Session；其他 Session/Case、Evaluator/Launcher/Broker 源码、其他 mode、上游密钥及私有 Pi 路径不可访问。Candidate Worker 的文件视图按当前范围不做结论。
- [ ] 确认工具列表没有 Web Search/Web Fetch，Shell/Python 公网连接失败；模型请求仍通过当前 Gateway；不变更受信任 NPU Runtime、HCCL 或管理员 SSH。

## 完成标准与停止条件

只有真实 Agent UID 下的 Runtime 可读、Pi private、Shell 子 Sandbox、Socket、Gateway、会话归档与当前 Session 可见性全通过后才能删除旧路径。若需要放开整个 HOME、让 Agent 读取 Broker 源码或改变 Candidate Worker/NPU 身份才能运行，停止并缩小访问范围；不得以旧路径作为替代方案。
