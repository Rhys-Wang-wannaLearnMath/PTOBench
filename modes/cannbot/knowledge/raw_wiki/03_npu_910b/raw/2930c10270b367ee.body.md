Therefore, to reduce scalar computations on the operator kernel, some computations are executed on the host. In this case, you need to compile the <a href="atlas_ascendc_10_0064.html">tiling code on the host</a>. Note that the dependent header file needs to be imported when the tiling API of the high-level APIs is called or the tiling structure parameter of the high-level APIs is used in the program.
