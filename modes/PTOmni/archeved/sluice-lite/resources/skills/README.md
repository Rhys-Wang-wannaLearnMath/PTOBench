# SLUICE Lite skills

This folder holds one small, always-on PyPTO optimization skill consolidated from the reviewed CANNBot `pypto-op-perf-tune`, `tune-frontend`, `tune-incore`, `tune-swimlane`, and `perf-analyzer` skills. It keeps current API, source-level optimization, and evidence-reading guidance while leaving Case contracts, tool schemas, permissions, and budgets to PTOBench. Its full text is included in the initial Pi prompt and frozen into the Session for reference.

It covers source-level PyPTO reasoning and how to interpret performance evidence. Case contracts, available hardware, editable options, benchmark commands, and action budgets remain in `.benchmark_context/README.md`; this skill does not duplicate them or add new tools.
